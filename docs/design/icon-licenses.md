# Shared icon licenses

The local shared icon registry copies the regular-weight geometry from
[Phosphor Core v2.0.8](https://github.com/phosphor-icons/core/tree/v2.0.8),
pinned to commit `d42782b2abe747d904b971ccab48b182a1455f86`.
