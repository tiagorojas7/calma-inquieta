## STOP conditions

- B9 (`period_material_offer`) is not merged when E6 starts: stop; E0-E5 may proceed.
- Admin shell (change 3 F0a/F0b) or admin gate B1b is not merged when E8 starts: stop; do not edit `src/app/**` admin layout from this change.
- Any seat-claim contract test passes on the fake but fails on Drizzle: stop, fix the SQL, never relax the contract.
- The concurrency test is flaky in CI: stop, do not retry-until-green; analyze lock behavior.
- A slice would exceed about 1,000 changed lines including tests: split before continuing, never compress tests.
- Owner answers change the data model (see blocking questions): re-open `design.md` and the affected specs before E3.
- Drizzle Kit generates changes to existing tables: stop, the migration must stay additive.
- `pnpm lint` reports a boundary violation: fix the structure, never the rule.
