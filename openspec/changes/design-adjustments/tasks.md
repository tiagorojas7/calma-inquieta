## Global rules (apply to every task)

- **Tags.** `[BACK]`: `src/modules/**`, `src/testing/{fakes,contracts,db,media}/**`, `tooling/**`, `public/**`, `docs/media/**`, `openspec/**`. `[FRONT]`: `src/app/**`, `src/testing/{fixtures,ui}/**`, `docs/design/**`. `[OWNER]`: steps no agent can do (PR merge, label decisions, copy review, any remote action). One branch per PR. Inside a PR, BACK tasks land first and FRONT tasks rebase on that branch; a content-shape change and the components that read it land in the same commit so every commit typechecks.
- **Commands.** Run everything through `corepack pnpm`. Focus a test with `corepack pnpm test <path>`, never `corepack pnpm test -- <path>`. A `*.ui.test.tsx` runs in the `ui` project.
- **Strict TDD.** Every behavior task is RED (write the test, run it, see it fail, record the failure in the PR notes), then GREEN (minimum code), then REFACTOR. Tests ship in the same commit as the behavior. Data-only work (binaries, registry rows, ledger rows) has no RED of its own; the task names the test that covers it.
- **Commits.** Conventional Commits only. NEVER a `Co-Authored-By` line or any AI attribution. One work unit per commit; every commit leaves `typecheck` and `test` green. The working tree carries an unrelated owner modification of `wrangler.jsonc` and an untracked `openspec/changes/archive/2026-10-13-design-system-and-public-site/.gentle-ai-instance`: never stage them (only DA-5R may edit `wrangler.jsonc`, from a clean file).
- **Local gate (end of every PR phase).** `corepack pnpm lint`, `corepack pnpm typecheck`, `corepack pnpm test`, `corepack pnpm format:check`, `corepack pnpm build`. All must exit 0. Coverage (`corepack pnpm test:coverage`) stays at 90 % lines and branches on `site-content/domain/media.ts` and the changed `content-rules.ts` code.
- **Architecture.** Never weaken `eslint.config.ts` or `tooling/architecture/architecture.test.ts`. No new element and no new package (sharp arrives with PR #51). `ui` stays structural: no module, context or composition import. `src/app/media/preload.ts` is `delivery`.
- **Copy.** Every new string and alt text is es-AR (voseo where it addresses the visitor) and passes `findCopyViolations`.
- **Visual check (FRONT slices that render pages: DA-3, DA-4, DA-5, DA-6, DA-7).** Before the PR, run `corepack pnpm dev` and take real-browser screenshots at **360, 1024 and 1440 px** width of every page the slice adds or changes, in each state the slice introduces: loop playing, loop paused by the user, and reduced-motion (DevTools Rendering "Emulate prefers-reduced-motion: reduce") for DA-5; motion on and reduced-motion for DA-6; claims stub for DA-7. Check no horizontal scroll at 360 px. Attach them to the PR and record in the PR body which data was used. Screenshots are never committed. DA-1 and DA-2 render nothing and record "N/A" with the reason.
- **Performance and motion manual checks (recorded in the PR body of the slice that owns them; design §11.2).** Lighthouse CLI mobile preset on the built site (`corepack pnpm build`, then `corepack pnpm exec wrangler dev`): LCP at most 2.5 s and the LCP element is the hero still (DA-3, re-run in DA-5); CLS 0 from media and motifs (DA-3 to DA-6); DevTools Network at 360 px with cache disabled: one image request above the fold and no request for an image that is not rendered (DA-3), no video request before the tile is reached (DA-5); reduced motion: cord static, butterfly at its perch, loop poster only with zero video bytes (DA-5, DA-6).
- **Remote actions.** Deploys, preview requests and anything behind Cloudflare Access need the owner's explicit authorization of destination, operation and credential/session; an agent that lacks it stays local and asks. The preview range check (task 5.14) is such a step.
- **Edit authority.** Backticked paths on task lines are edit targets; paths only read carry `(read-only)`. The media workspace (`../CalmaInquieta-media`, `../CalmaInquieta-media-tool`) is read-only and outside the repository; originals are never committed.
